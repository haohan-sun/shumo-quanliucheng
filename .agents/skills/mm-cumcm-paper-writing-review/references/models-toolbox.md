# 模型工具箱与选型

> 按题型选模型，而不是会什么套什么。官方评阅综述明确批评"套用现成模型、仅调参输出结果"的浅层做法——任何模型都要结合题目机理做适配改造，并写清改造点。

## 快速选型表

| 题目问的是 | 优先考虑 | 备选/组合 |
|---|---|---|
| 评价/排序/选优 | 熵权-TOPSIS、AHP+模糊综合评价 | 灰色关联、数据包分析 DEA、主成分赋权 |
| 预测（时间序列） | ARIMA、季节分解 | 灰色 GM(1,1)（小样本）、LSTM（大数据量）、组合预测 |
| 预测（因果回归） | 多元回归、逐步回归 | 岭回归/LASSO（共线性）、随机森林（非线性） |
| 优化（确定、连续/整数） | 线性/整数/非线性规划 | 动态规划、二次规划 |
| 优化（随机需求/库存） | 报童模型、随机规划、（s,S）库存策略 | 鲁棒优化、机会约束规划 |
| 优化（多目标） | 加权/ε约束法 + NSGA-II | Pareto 前沿展示、层次分析法定权 |
| 调度/路径/分配 | 图论与网络流、整数规划 | 启发式：GA/SA/蚁群/模拟退火 |
| 分类/聚类 | K-means、层次聚类、判别分析 | 随机森林、SVM（要讲清核与调参） |
| 相关/影响分析 | Spearman/Pearson（先检验前提！） | 回归系数显著性、灰色关联 |
| 机理过程（物理/化学/生态） | 微分方程模型、稳定性分析 | 元胞自动机、蒙特卡洛仿真 |
| 排队/服务系统 | M/M/c 等排队论模型 | 离散事件仿真 |
| 统计推断 | 假设检验、分布拟合（K-S/卡方） | 贝叶斯估计、Bootstrap 置信区间 |

## 选用与组合的纪律

1. **统计方法先验前提**：用 Pearson 前做正态性检验（不行就 Spearman）；用回归前看残差与共线性；拟合分布要做优度检验（K-S/卡方）并报告统计量。官方细则明确："无视方法适用前提"直接扣分。
2. **只做描述性统计/画图不够**：数据规律要落到"分布类型 + 时间效应（季节/周期/节假日/趋势）+ 检验"层面才拿全分。
3. **耦合决策不能拆开套模型**：例如"定价与补货"要放进同一个优化模型联立求解；先预测再单独优化会被判"割裂建模、脱离实际"。
4. **多目标要展示取舍**：给 Pareto 前沿或权重敏感性，而不是拍一个权重的单目标。
5. **启发式算法要交代清楚**：编码方式、目标函数、关键算子、参数、终止条件、多次运行取最优；最好与小规模精确解/贪心解对比验证。
6. **智能算法不是越多越好**：一篇文章 2~4 个核心模型足够，关键是每个都用透（检验+对比+解释）。
7. **结果对比是加分项**：官方细则在多问都写了"不同模型/方案下结果对比，酌情加分"——同一问给两个可行方案并对比，是冲国奖的常见操作。

## 常见"挂模型"陷阱（评审按此扣分）

- AHP 打分矩阵没有一致性检验，或权重全凭拍脑袋。
- 灰色预测用在有明显周期性/季节性的数据上且不检验精度。
- LSTM/深度学习在几百条小样本上跑，结果不可复现、无检验。
- 优化结果数量级脱离现实（利润、价格、补货量明显不合理）——出题人综述重点批评项。
- 蒙特卡洛不给收敛性说明（模拟次数与方差）。
- 引用"某某改进算法"但看不出相对基线改进在哪、提升多少。

## 求解工具与附录对应

- 常用：Python（NumPy/Pandas/SciPy/scikit-learn/Gurobi-Pulp/CVXPY）、MATLAB、LINGO、SPSS/R。
- 附录代码必须与正文模型一一对应、可运行；求解同一模型的脚本命名清晰（`q1_fit.py`、`q2_optimize.py`）。
- 结果复现路径写清楚：数据文件 → 运行顺序 → 生成哪个图表。

# 摘要写作

> 摘要是整篇论文权重最高的一页。评阅工作量极大，第一轮筛选基本只看摘要是否"逐问有方法、有结果、有数值"。摘要不过关，正文写得再好也难进高等奖池。

## 铁律

1. **逐问覆盖**：每一问都要有独立的一段或明确的几句话，写清"建模思路→模型/方法名→求解算法→**具体数值结果**"。
2. **必须有数值**：空说"求解得到最优策略"没有分量；要写成"在约束 X 下最大收益 3.42 万元，最优补货量 271kg，对应定价 8.7 元/kg"这样的具体结论。结果过多的问可取 2~3 个代表性数值。
3. **不出现"首先/其次/然后"式流水账**：用"针对问题一，建立……模型，采用……方法，求解得到……"的句式直接给干货。
4. **方法链完整**：数据处理（异常值/缺失值怎么处理）在数据类题目里也值得一句话，因为评分细则常给数据处理单独分值。
5. **检验与评价收尾**：一两句灵敏度分析/误差分析/稳健性检验，说明结果可信；再一句模型优点与推广价值。
6. **关键词 3~5 个**：写核心模型与方法名（如"随机优化；报童模型；K-means 聚类；整数规划"），不要写"MATLAB、数学建模"这类无信息量词。
7. 一页以内；无英文翻译；不出现任何身份信息。

```

针对问题一：为分析××规律，先对数据做××处理（剔除异常××条/插补缺失×），
```

## 常见失分写法（评审时按此排查）

- 通篇只有"我们用了什么方法"，没有任何一个数值结果。
- 摘要只覆盖前两问，后面的问"详见正文"。
- 出现"本文首先……然后……最后……"且每句都没有模型名和结果。
- 把代码细节、公式推导写进摘要。
- 关键词写成题目里的名词堆砌，看不出用了什么模型。

## 自查五问（交付前逐条过）

1. 是否每一问都有独立覆盖？
2. 是否每问都有至少一个具体数值/规律性结论？
3. 方法链是否完整（数据处理→模型→算法→结果）？
4. 是否有检验/灵敏度/误差的交代？
5. 关键词是否为模型与方法名、数量 3~5 个？

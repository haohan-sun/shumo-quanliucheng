# 工具与配置

这里是基础设施区，不是比赛成果区。包含：

- `.agents/skills/`：数学建模工作流 Skill；
- `.codex/agents/`：角色配置；
- `scripts/`：状态、校验、哈希、合规和打包脚本；
- `configs/` 与 `schemas/`：路径、赛事配置和数据合同；
- `reports/`：环境与工作流检查报告；
- `third_party/`：第三方方法来源说明。

请从项目根目录使用 `run.ps1`。代码在 `../03_建模工作区/src/`，论文在
`../04_论文与提交/paper/`，两者不会写入本目录。

队员快速上手请读根目录 `数学建模工作区使用说明.md`。

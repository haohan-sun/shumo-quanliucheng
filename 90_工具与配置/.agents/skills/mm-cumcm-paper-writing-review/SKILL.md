# 数模论文写作与评审

本 Skill 由仓库所有者原创提供，并为公开模板做了路径参数化与来源边界整理。
它是 CUMCM 专项能力，不替代通用 `mm-paper-writing`、跨工件审计
`mm-paper-defense` 或最终提交检查 `mm-compliance`。

本技能面向高教社杯全国大学生数学建模竞赛（CUMCM）论文，支持三种工作模式，开工前先判断用户属于哪种：

1. **写作模式**——从零撰写或修改论文的某个部分（摘要、某一问的建模求解、附录等）。
2. **评审模式**——以国赛评委视角对一篇论文打分、找问题、给修改优先级。
3. **范文模式**——从本地论文库检索同类型获奖论文供用户对标学习。

范文模式使用可选论文库：优先读取环境变量 `CUMCM_PAPER_LIBRARY` 指向的目录，
未设置时检查项目内 `02_参考文献/优秀论文库/`。用法见
`references/paper-library.md`；目录不存在时明确报告未就绪，不得虚构论文、奖项或评阅材料。

## 硬约束：先核对当届官方格式规范

凡是动笔写或改论文，先把当届官方规则保存到 `01_题目与要求/` 并由
`mm-compliance` 核验，再读取 `references/format-spec.md` 作为工作清单。参考文件不是
当届规则真源；若二者冲突，以当届官方文件为准。

- 电子版首页必须是摘要专用页；承诺书和编号专用页不得放进电子版。
- 正文（第四页起）不超过 30 页，**不要目录**；页码从摘要页起算。
- 全文任何位置（含附录、代码、文件名）不得出现姓名、学校、赛区等身份信息。
- 附录必须含支撑材料清单和**全部完整可运行的源程序**；无程序须写明"本论文没有用到程序"。
- 引用他人成果（含网上资料、AI 生成内容的使用）须按规范标注参考文献或按要求声明。

## 写作模式

按论文推进顺序处理，各环节要领：

1. **摘要**（全篇最重要，评委第一轮基本只看摘要）——先读 `references/abstract.md`，按其中的结构模板和"每问必有数值结果"的铁律来写或改。
2. **正文结构**——按 `references/structure-and-style.md` 的章节骨架组织：问题重述→问题分析→模型假设→符号说明→模型建立与求解（逐问）→模型检验→模型评价→参考文献→附录。该文件同时含图表规范和语言风格清单。
3. **模型选型**——用户问"这题用什么模型"或某问建模卡住时，读 `references/models-toolbox.md`；特别注意"套用现成模型不结合题意改造"是官方评阅里点名的低分原因。
4. **交付前自查**——写完或改完后，按"评审模式"的轻量流程（见下）跑一遍格式红线和摘要质量检查，再交付。

写作时的通用要求：

- 语言用正式书面语，避免口语和营销腔；模型与算法必须写出**关键步骤的文字说明**，不能只堆公式或只贴代码。
- 每问的结果都要落到具体数值、图表，并给出现实解释（例如"工作日与周末需求差异已体现在定价中"这类贴合题意的结论）。
- 结果必须做合理性检验：数量级是否贴合现实、是否回应了题目的每一个约束。

## 评审模式

拿到论文（PDF/Word/文本）后：

1. 读 `references/review-guide.md`，并对照当届可验证的官方评阅材料，按假设合理性、建模创造性、结果正确性、表述清晰性和逐问给分点思路评阅。
2. 先读摘要并单独给摘要打分，再逐问评建模与结果，最后评全文结构与规范。
3. 若论文是 PDF，用 `scripts/pdftext.py` 抽取文本（用法见文件头注释）；图表质量需要视觉判断时提示用户逐页查看。
4. 输出评审报告，结构固定为：

```
## 总评（一段话：论文定位 + 预估档次：国一候选/国二/省奖/不合格 + 3 个最大亮点）
## 分项评分（表格）
| 维度 | 满分 | 得分 | 一句话理由 |
（维度至少含：摘要、假设合理性、建模与创造性、求解与结果、模型检验、表述与规范）
## 逐问评析（每问：给分点命中情况 → 证据（引用原文位置）→ 问题）
## 扣分与风险清单（含格式红线检查结果，标注"可能取消评奖资格"级别的问题）
## 修改优先级（P0 必改 / P1 应改 / P2 可选，每条给出具体可操作的改法或替换措辞）
```

5. 评审时给的每条问题都要有原文证据（页码/章节定位），不允许凭空推断；凡是“评委可能怎么看”的判断，都要标注已核验的当届官方材料或明确写成经验性判断。

轻量自查（写作模式末尾用）：只跑格式红线清单 + 摘要五问（是否逐问覆盖、是否每问有数值、方法链是否完整、是否有检验、关键词是否恰当），不输出完整报告。

## 范文模式

用户想找范文、对标往届、或给"XX 类型题目该怎么写"找例证时：

1. 读 `references/paper-library.md`，按“题型/年份/模型方法”在已配置的论文库中定位 3–5 篇同类型、来源可核验的论文。
2. 用 `scripts/pdftext.py` 抽取摘要与目录部分做对比分析，输出"这些论文在结构、方法链、摘要写法上的共性"，而不是大段摘抄原文。
3. 提醒用户：范文用于学习套路与深度，严禁照抄模型结构、文字与代码（查重与 AI 痕迹审查都会命中）。

# 可选论文库使用指南

论文库不是本 Skill 的内置依赖。优先读取环境变量 `CUMCM_PAPER_LIBRARY` 指定的
目录；未设置时检查项目内 `02_参考文献/优秀论文库/`。目录不存在就跳过范文模式并
报告缺口，不得猜测论文内容、奖项或官方评价。

## 建议目录结构

```text
优秀论文库/
├── index.json                 # 年份、题号、标题、队号、来源 URL、文件路径、核验状态
├── 官方展示/                  # 仅保存来源可核验的官方公开论文
├── 官方获奖名单/              # 用于核对奖项，不以文件名推断
├── 官方评阅材料/              # 评分细则、出题人综述及原始链接
└── 其他赛事/                  # 与 CUMCM 分开标记，不混称国赛论文
```

## 检索方法

1. 先查 `index.json`，按年份、题号、题型和模型方法筛选。
2. 逐篇核验原始链接、赛事、年份、题号与奖项；无法核验的标为“来源待核”。
3. 优先选择 3–5 篇近年官方展示论文，比较摘要、方法链、检验和表达，不做长段摘抄。
4. PDF 有文本层时可运行：

   ```powershell
   python .agents/skills/mm-cumcm-paper-writing-review/scripts/pdftext.py <pdf路径> [起始页] [页数]
   ```

   扫描版或逐页图片版需要视觉阅读。

## 使用纪律

- 范文只用于学习结构、深度和证据组织，严禁照抄模型表述、文字与代码。
- 引用论文观点、数据或图表时必须按竞赛要求列参考文献并标出正文引用。
- 不把研究生赛、国际赛或第三方合集误标为 CUMCM 官方获奖论文。
- 论文库中的格式经验不能替代当届官方规则。
